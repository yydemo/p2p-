# p2p-分布式计算程序 / p2p- Distributed Computing Program

> 语言说明 / Language note：本仓库文档为中英双语，先中文后英文。 / This repository's documentation is bilingual: Chinese first, then English.

## 1、概要 / 1. Summary

分布式计算原理，p2p 分布计算，覆盖个人电脑、手机 APP、服务器等。发挥余额计算能力。

Distributed computing principles and P2P distributed computation, covering personal computers, mobile apps, servers and more, to make use of spare (idle) computing capacity.

## 2、基础 / 2. Foundations

① 分布式计算原理。主要源码来源于博士研究或网络开源代码；成熟开源平台；

① Distributed computing principles. The main source code comes from doctoral research or open-source code found online, and from mature open-source platforms.

② Server 端。LINUX 系统（centos 或其他 linux），数据库 mysql（可采用 ali 的分布式 mysql 数据库），后期数据量巨大时采用。

② Server side. A Linux system (CentOS or another Linux distribution) with a MySQL database (Alibaba's distributed MySQL database can be adopted later, when the data volume becomes very large).

## 3、分布计算平台 / 3. Distributed computing platforms

① 个人电脑。② 手机 APP。③ 服务器。④ 其他可计算通用代码计算器。

① Personal computers. ② Mobile apps. ③ Servers. ④ Other general-purpose devices capable of running computation code.

## 4、源代码架构 / 4. Source code architecture

① 开源分布式计算原理。② bt 程序源码及原理。

① Open-source distributed computing principles. ② BitTorrent (BT) program source code and its principles.
